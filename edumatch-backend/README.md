# edumatch-backend

Simple Express boilerplate for EduMatch.

Run locally:

```bash
cd edumatch-backend
npm install
npm run dev   # requires nodemon (dev)
# or
npm start
```

Endpoints:
- GET /api/tutors
- GET /api/tentors (alias)

Suggested initial packages:
- express, cors, pg
- For ORM: prisma (@prisma/client) or sequelize
